# CryptoLab 🔐

A beginner-friendly Encryption & Decryption Simulator developed as part of the DecodeLabs Cyber Security Industrial Training Program.

## 📌 Project Overview

CryptoLab demonstrates the fundamentals of classical cryptography through Caesar Cipher and Vigenère Cipher implementations.

The project allows users to encrypt and decrypt messages while learning how classical encryption algorithms transform plaintext into ciphertext.

## ✨ Features

* Caesar Cipher Encryption
* Caesar Cipher Decryption
* Vigenère Cipher Encryption
* Vigenère Cipher Decryption
* Adjustable shift values
* Interactive cipher visualizations
* Real-time encryption and decryption
* Character frequency analysis
* Educational cryptography interface

## 🔐 Encryption Techniques

### Caesar Cipher

A substitution cipher that shifts letters by a fixed number of positions.

Example:

```text
HELLO
Shift: 3
```

Output:

```text
KHOOR
```

### Vigenère Cipher

A polyalphabetic cipher that uses a keyword for encryption.

Example:

```text
Message: HELLO
Key: KEY
```

Output:

```text
RIJVS
```
